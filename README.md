# Data Science Learning

A practical learning project focused on Data Science, data analysis,
data visualization, and machine learning.

## Objectives

- Learn Data Science concepts through practical examples.
- Practice data cleaning and preprocessing.
- Perform Exploratory Data Analysis (EDA).
- Implement machine learning algorithms.
- Evaluate models using appropriate metrics.
- Build reproducible projects for a professional portfolio.

## Topics

- Data Analysis with Pandas and NumPy
- Data Visualization with Matplotlib and Seaborn
- Data Preprocessing
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees and Random Forest
- Support Vector Machines (SVM)
- Linear Regression
- K-Means Clustering
- Model Evaluation and Comparison
- Data Collection and Web Scraping

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- JupyterLab

## Installation

Install the required libraries:

    python3 -m pip install -r requirements.txt

Start JupyterLab:

    jupyter lab

## Learning Approach

Each notebook focuses on understanding concepts, implementing
solutions, visualizing results, and interpreting model performance.

Notebooks should be tested from beginning to end before publication.
Useful outputs, visualizations, and evaluation results should be retained.

## Data Usage

Check dataset licenses and redistribution permissions before publishing
datasets in this repository.
